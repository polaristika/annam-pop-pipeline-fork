### 📂 `classify/` - PDF Classification

**Purpose:** Determine PDF type, language, and processing route

#### **english_vs_indic.py** (Advanced Classification)
- **Function:** `classify_pdf_advanced(pdf_path)`
- **Method:** FastText lid.176.bin model (176 languages)
- **Features:**
  - Detects 22 Indic languages
  - Confidence scoring (0.0 - 1.0)
  - Garbled text detection
  - Per-page voting system
- **Returns:** `{lang_guess, lang_conf, lang_votes, garbled_detected}`

#### **router.py** (Routing Logic)
- **Function:** `main()`
- **Purpose:** Route PDFs to Phase 1 or Phase 2 based on classification
- **Input:** `pdf_inventory.csv`
- **Output:** 
  - `worklist.parquet` (Phase 1: digital English)
  - `hold_non_en_or_non_digital.csv` (Phase 2: everything else)
- **Logic:**
  ```python
  if digital_guess == True and lang_guess == 'en':
      route = "digital_en"  # Phase 1
  else:
      route = "hold"  # Phase 2 or later
  ```

---

### 📂 `extract/` - Content Extraction

**Purpose:** Extract text, tables, and images from PDFs

#### **docling_runner.py** (Structure Extraction)
- **Function:** `extract_with_docling(pdf_path, output_dir)`
- **Technology:** Docling library
- **Extracts:**
  - Document structure (headings, paragraphs, tables)
  - Page layouts
  - Text with positional information
- **Output:** `doc_garbled.md` (Markdown with structure)

#### **ocr_runner.py** (Optical Character Recognition)
- **Function:** `run_ocr_on_pdf(pdf_path, state, output_dir)`
- **Technology:** EasyOCR
- **Features:**
  - State-aware language selection
  - Image preprocessing
  - Confidence scoring
- **Output:** Clean text per page

#### **direct_doc_generator.py** (Direct Processing)
- **Function:** `generate_doc_md_direct(pdf_path, artifact_dir, doc_id)`
- **Purpose:** Simplified extraction for clean PDFs
- **Used By:** Phase 1 (English PDFs)

---

### 📂 `ingest/` - PDF Inventory

**Purpose:** Discover, scan, and classify all PDFs

#### **inventory.py** (Main Inventory Module)
- **Functions:**
  - `iter_pdfs(data_root)` - Iterator over all PDFs
  - `classify_pdf_simple(pdf_path)` - Basic classification
  - `run_inventory(data_root, output_path)` - Full scan
- **Process:**
  1. Scan `data/raw/POP Bank/` directory
  2. Extract metadata (size, pages, MD5 hash)
  3. Classify each PDF (basic + advanced)
  4. Save to `pdf_inventory.csv`
- **Output Fields:**
  - `file_path, state, size_bytes, md5, page_count`
  - `class, digital_guess, lang_guess, lang_conf`
  - `garbled_detected, status`

---

### 📂 `structure/` - Format Conversion

- **Function:** `stitch_json_with_ocr(garbled_json, ocr_text, output_json)`

- **Used In:** Phase 6 (garbled file processing)

- **Function:** `batch_convert_directory(input_dir, output_dir)`

  inventory_csv: pdf_inventory.csv
  artifacts_dir: artifacts

    lang_guess: en

│   ├── pdf_inventory.csv           # Master inventory (565 PDFs)
│   ├── classification_digital_en.csv     # 152 English PDFs
│   ├── classification_digital_indic.csv  # Indic PDFs
│   ├── classification_scanned_en.csv     # Scanned PDFs

│   ├── hold_non_en_or_non_digital.csv    # Phase 2+ queue

### Key Files

#### **data/raw/POP Bank/** (Source PDFs)
- **Size:** ~1-2GB
- **Organization:** By state (26 folders)
- **Files:** 565 PDF documents
- **Not in Git:** Too large, excluded by .gitignore

#### **data/metadata/pdf_inventory.csv** (Master Inventory)
- **Rows:** 565 (one per PDF)
- **Columns:** 15 fields
- **Key Fields:**
  - `file_path` - Relative path to PDF
  - `state` - State name
  - `md5` - File hash (unique ID)
  - `class` - digital_en, scanned_en, etc.
  - `lang_guess` - Language detection result
  - `status` - pending, processed, error

#### **data/metadata/classification_*.csv** (Classification Results)
- **Purpose:** PDFs grouped by classification
- **Files:**
  - `classification_digital_en.csv` (152 PDFs) - Phase 1
  - `classification_digital_indic.csv` - Phase 2
  - `classification_scanned_en.csv` (42 PDFs) - Phase 3
  - `classification_error.csv` (20 PDFs) - Need recovery

## File Naming Conventions

### PDFs
- **Original:** Keep original filenames from states
- **Example:** `Package_of_Practices_Rice.pdf`

### Generated Files
- **Document ID:** First 12 characters of MD5 hash
- **Example:** `9c2cbe1ce58a/`

### JSON/Markdown
- **Standard:** `doc.json`, `doc.md`
- **Translated:** `doc_translated.json`, `doc_translated.md`
- **Garbled:** `doc_garbled.json` (before cleanup)

### Images
- **Format:** `img_001.jpg`, `img_002.png`
- **Location:** `images/` subfolder in artifact directory
